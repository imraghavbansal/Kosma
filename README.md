# TraceOS

**Know what a change will break before you ship it.**

TraceOS is an AI change-intelligence system: propose a prompt or model change, it finds
comparable historical executions, replays the candidate config against them, and shows
you an evidence-backed Blast Radius Diff with a Ship/Modify/Block recommendation —
before you deploy anything.

See [PRODUCT-SPEC.md](PRODUCT-SPEC.md) for the product thesis and [docs/](docs/) for
architecture, schema, API design, and the phase-by-phase build plan.

## Tech stack

| Layer | Choice | Why (short) |
|---|---|---|
| Frontend | Next.js (App Router) + TypeScript + Tailwind | Server Components for read-heavy pages, TanStack Query only where polling/caching an async job earns it |
| Backend | Python + FastAPI + SQLAlchemy + Alembic | Async-native API; Python matches the SDK language the target users (RAG/agent developers) already write in |
| Database | Postgres + pgvector, hosted on Supabase | Cohort-matching similarity search lives in the same store as the relational data; Supabase ships pgvector pre-enabled (no Windows build pain, no Docker) |
| Background jobs | In-process asyncio tasks | V1's scale doesn't need a broker; see `docs/architecture.md` for the full tradeoff |
| Auth | Single shared secret (dashboard) + hashed per-project API key (ingestion) | Single-tenant portfolio deployment; schema keeps `organization_id`/`project_id` for later |
| AI calls | Mock provider only | Deterministic, zero-cost, clearly labeled demo data — see PRODUCT-SPEC.md |

Full rationale for every decision (Problem → Options → Decision → Reason → Tradeoff) is
in [docs/architecture.md](docs/architecture.md).

## Quick start (no Docker required)

Requires a free [Supabase](https://supabase.com) project (Postgres + pgvector, hosted).

```bash
git clone https://github.com/imraghavbansal/TraceOS.git
cd TraceOS
cp .env.example .env
# edit .env: set DATABASE_URL to your Supabase connection string,
# and TRACEOS_DASHBOARD_SECRET to whatever you want to log in with
```

Backend:

```bash
cd apps/api
python -m venv .venv && source .venv/bin/activate   # .venv/Scripts/activate on Windows
pip install -r requirements.txt
alembic upgrade head
uvicorn traceos_api.main:app --reload
```

Frontend (separate terminal):

```bash
cd apps/web
npm install
npm run dev
```

Open http://localhost:3000 and sign in with `TRACEOS_DASHBOARD_SECRET` from your `.env`.
Backend API docs (auto-generated by FastAPI): http://localhost:8000/docs

### Optional: Docker

`infra/docker-compose.yml` containerizes the API and web processes if you'd rather not
run them natively. It still expects `DATABASE_URL` in `.env` to point at Supabase — it
does not run Postgres locally.

## Running the backend tests

```bash
cd apps/api
python -m pytest tests/ -v
```
