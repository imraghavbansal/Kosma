# Kosma API Design (V1)

Base path: `/v1`. OpenAPI docs auto-generated by FastAPI at `/docs`.

Two auth schemes:
- **Ingestion** (`POST /v1/traces`): `Authorization: Bearer <project_api_key>`, checked
  against `projects.api_key_hash`.
- **Dashboard/query/change-engine endpoints**: session cookie set by logging in with
  `KOSMA_DASHBOARD_SECRET`.

All list endpoints support `?limit=&offset=` pagination and return
`{items: [...], total: int}`. All errors return
`{error: {code, message, request_id}}` with the appropriate HTTP status.

## Ingestion

```
POST /v1/traces
  body: { trace_ref, agent_id, agent_config_id, workflow_tag, segment_tags,
          input_text, model_provider, model_name, latency_ms,
          input_tokens, output_tokens,
          spans: [ { span_type, name, input, output, metadata, latency_ms,
                     parent_ref, tool_call?, retrieval_event? } ] }
  -> 202 { trace_id, status: "queued" }
```
The SDK submits one complete trace payload on completion (no partial/streaming ingestion
in V1 - keeps ingestion simple and fast).

## Agents & configs

```
GET  /v1/agents
GET  /v1/agents/{id}
GET  /v1/agents/{id}/configs
POST /v1/agents/{id}/configs
  body: { kind: prompt|model, version_label, prompt_text?, model_provider?,
          model_name?, temperature?, params? }
  -> 201 { config }
```

## Traces (evidence / secondary nav)

```
GET /v1/traces?workflow_tag=&agent_id=&status=&source=&q=
GET /v1/traces/{id}          -> trace + spans + tool_calls + retrieval_events, tree-shaped
```

## Failure clusters & evaluations (substrate, secondary nav)

```
GET /v1/failure-clusters
GET /v1/failure-clusters/{id}          -> cluster + member traces
GET /v1/evaluations?trace_id=
```

## Change engine (the core product surface)

```
POST /v1/change-proposals
  body: { agent_id, baseline_config_id, candidate_config_id, description }
  -> 201 { change_proposal }

GET  /v1/change-proposals?agent_id=&status=
GET  /v1/change-proposals/{id}

POST /v1/change-proposals/{id}/analyze
  -> 202 { status: "analyzing" }   (enqueues Arq job: cohort match -> replay -> impact report)

GET  /v1/change-proposals/{id}/impact-report
  -> 200 { recommendation, confidence, cohort_size, sample_size,
           overall_metrics, segment_metrics, evidence: [...] }
     404 if not yet analyzed

POST /v1/change-proposals/{id}/ship
  -> 200 { change_proposal }   (sets status=shipped, shipped_at=now())

GET  /v1/change-proposals/{id}/prediction-outcome
  -> 200 { predicted_metrics, actual_metrics, prediction_error }
     404 if not enough post-ship data yet
```

## Regression tests

```
POST /v1/impact-reports/{id}/regression-tests
  body: { segment?, max_count? }
  -> 201 { regression_tests: [...] }   (generated from worst-regressed evidence rows)

GET  /v1/regression-tests?project_id=&status=
GET  /v1/regression-tests/{id}
```

## Analytics (secondary)

```
GET /v1/analytics/overview     -> total traces, success rate, cost, latency p95,
                                   open change proposals, recent impact reports
```

## Demo/seed (dev convenience, not part of the product surface)

```
POST /v1/demo/seed
  -> 202 { status: "seeding" }   (regenerates the seeded demo corpus; disabled outside
                                   ENVIRONMENT=demo)
```

## Auth

```
POST /v1/auth/login   { secret } -> sets session cookie
POST /v1/auth/logout
```
